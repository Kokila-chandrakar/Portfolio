🌐 AI & ML Portfolio Website

A modern and responsive portfolio website built using React, TypeScript, Tailwind CSS, and Font Awesome. This portfolio showcases projects, technical skills, and contact information with a clean UI and interactive design.

🚀 Features
Responsive modern UI
Smooth scrolling navigation
Interactive hero section
Skills showcase with progress bars
Featured AI & ML projects section
Contact and social media links
Glassmorphism design effects
Fully customizable portfolio layout
🛠️ Tech Stack
React
TypeScript
Tailwind CSS
HTML5 & CSS3
Font Awesome
